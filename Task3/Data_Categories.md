## Аппаратные средства защиты
- Шифрование на уровне хранения и передачи данных с применением SED-накопителей и шифрующего сетевого оборудования

## Программные средства защиты
- ПО для контроля доступа с применением RBAC. В данном случае выбран Active Directory в связи с тем, что он уже был развернут на оборудовании компании.
- ПО для обнаружения утечек данных, DLP
- ПО для контроля за потоками данных. Для компании выбран DataGrail в связи с его широкими возможностями интеграции и популярностью среди среднего бизнеса
- Использование шифрования на уровне сети с применением SSL
- Использование шифрования на уровне хранения с использованием AES
- Использование защищенной сети для внутренних сервисов с доступом по VPN
