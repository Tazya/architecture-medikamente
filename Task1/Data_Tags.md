# Защита данных

## Список тегов

- PII (Personally Identifiable Information) — персонально идентифицируемая информация
- PHI (Protected Health Information) — защищённая медицинская информация
- medical_records — медицинские записи
- financial_data — финансовые данные

На данном этапе теги будут выставляться в системах, которые принимают и сохраняют данные первыми. Решение принято в связи с тем, что компания только начинает трансформацию и не имеет устоявшейся модели.
Впоследствии возможно внедрить инструменты автоматической классификации данных, такие как BigId, Collibra или Informatica Axon. В начальном этапе это нецелесообразно.

## Данные

**Пациент**

- ФИО (Теги: PII; Методы защиты: шифрование, доступ по ролям)
- Номер телефона (Теги: PII; Методы защиты: шифрование, доступ по ролям)
- Дата рождения (Теги: PII; Методы защиты: шифрование, доступ по ролям)
- Почта (Теги: PII; Методы защиты: шифрование, доступ по ролям)

**Пациент расширенные**

- Прописка (Теги: PII, Методы защиты: доступ по ролям)
- Адрес работы или учебы (Теги: PII; Методы защиты: доступ по ролям)
- Хронические заболевания (Теги: PHI; Методы защиты: обезличивание привязки к карточке, доступ по ролям)

**Операционные данные**

- Журналы приёма пациентов — содержат ФИО, номер телефона, дату рождения (Теги: PII, Методы защиты: шифрование, доступ по ролям)
- Учёт пациентов и платежей — Содержит ФИО и информацию об оплате услуг (Теги: PII, PHI, Методы защиты: шифрование, доступ по ролям)
- Медицинские карты - содержат конфиденциальные данные, необходимо усилить защиту (Теги: PII, PHI, Методы защиты: шифрование, доступ по ролям)
- Учёт анализов и результатов (Теги: medical_records, Методы защиты: обезличивание, доступ по ролям)
- Привязка анализов к медицинским картам (Теги: PHI, medical_records, Методы защиты: обезличивание, доступ по ролям)

**Бухгалтерские данные**

- Учёт денежных средств — в «1С:Бухгалтерия предприятия». (Теги: financial_data, Методы защиты: шифрование, доступ по ролям)
- Учёт товарно-материальных ценностей (ТМЦ) — в «1С:Торговля и склад». Программа интегрирована с «1С:Бухгалтерия предприятия». (Теги: financial_data, Методы защиты: доступ по ролям)

## Инструменты и меры защиты данных

- Шифрование данных на уровне базы данных и приложений.
- Ограничение доступа к данным по ролям и правам пользователей.
- Регулярные аудиты и мониторинг доступа к данным.
- Обучение сотрудников по вопросам защиты данных и конфиденциальности.
- Использование VPN и защищённых каналов связи для доступа к данным.
- Резервное копирование данных с шифрованием.
- Применение средств предотвращения утечки данных (DLP) для контроля передачи конфиденциальной информации.
- Внедрение платформы для управления данными, в конкретном случае это будет DataGrail, так как больше подходит для задач компании, включая управление PII и PHI, а также соответствие требованиям 152-ФЗ и GDPR.
